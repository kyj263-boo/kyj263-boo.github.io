# Netlify Functions

이 폴더의 코드는 **서버에서만 실행**됩니다. 공개 출력 폴더(`public/`)에 복사되지 않으므로
브라우저로 소스가 노출되지 않습니다.

## 규칙
- 서버 비밀값(예: Supabase `service_role` key, 외부 API 키)은 **코드에 하드코딩하지 말고**
  Netlify 대시보드의 **Environment variables**로만 주입하세요.
- 이 폴더의 파일을 `public/`에 복사하지 마세요. (빌드 스크립트가 자동으로 제외합니다.)

## 현재 상태
- 사이트는 Supabase를 브라우저에서 **anon key**로 직접 호출합니다. 따라서 서버 함수는
  지금 **필수가 아닙니다**. `health.mjs`는 구조 예시이자 배포 확인용입니다.
- 서버 함수가 필요해지는 경우(예시):
  - `service_role` key로만 가능한 작업을 서버에서 수행
  - 삭제/쓰기 권한을 서버에서 검증
  - 외부 API 키를 숨겨야 할 때
